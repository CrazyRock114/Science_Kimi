# 全面复盘与未来迭代计划（v1，待审核）

> 本文档合并了两部分：① 2026-07-30 三路全面审查（内容质量 / 代码质量 / UX 浏览器走查）的发现；② `research-and-plan.md` 第七节的原定待办方向。按迭代组织，每个迭代可独立交付。

## 一、审查总结

### 总体结论
产品完成度与工程质量都处于很高水平：**内容零科学性错误**、双语达教材级水准、412 道真题 mark scheme 分值 100% 一致、5000 个测试全绿、UX 走查 0 控制台错误、移动端无横向溢出。问题集中在**结构性缺口**而非质量缺陷。

### 内容维度（严重度降序）
- **[严重] 人教版线覆盖缺口**：初中物理九年级 10 章缺 6 章（电功率、电与磁、生活用电、能源、信息传递、内能利用——电功率和电与磁是中考核心）；初中生物八年级上册全册 + 八下"健康地生活"空白；初中化学"溶液"单元空白；初中物理八上的声/物态变化/质量密度空白。
- **[严重] 实验与知识点完全孤立**：102 个化学实验与知识点零互链，35 个无仿真的手写化学课零交互——而本可关联的实验就在隔壁。
- **[中等] 双轨体验差异**：转换课 75/75 理论页无正文（内容全藏在 narration 里，不听讲解就没得读）；手写课缺学习目标/词汇表/真题演练；30+ 对同主题双课（手写 ↔ IGCSE 转换）无互链。
- **[中等] 讲解音频 0 文件**：83 课剧本全部回退浏览器 TTS；手写课剧本覆盖率仅 11%（8/70）。
- **[轻微]** 转换课 summary 与 theory 首段逐字重复；3 课小测只有 2 题；个别学段标注偏宽；`lab/gas.ts` 5 处化学式未下标；2 处过期注释（igcse-statements 头部、narration 音频路径）。

### 代码维度
- **[严重] AI 后端公网暴露面无防护**（`server/handler.ts`）：CORS 默认 `*`、无鉴权、无限流、无输入长度上限——部署后任何人可烧 LLM token 额度。**正式上线 AI 功能前必须修复**。
- **[严重] README 与现状严重漂移**：新增知识点流程已变（需 `npm run extract:metas`）、缺 lab/cells/AI/IGCSE 全部板块、"纯静态无后端""全部原创"表述与实际矛盾。
- **[中等]** 45/70 手写知识点无 expectedResults 探针（与 README 承诺不符）；server/ 仅 prompts 有测试（handler/llm 零测试）；生成器依赖 gitignore 的 `.reference/` 不可复现；无 ESLint。
- **[轻微]** mmx 内核每次渲染算两遍；chunk 加载失败静默变 404；primitive 清单三处重复；content 层反向依赖 components 层类型；测试全跑 jsdom 偏慢（120s）。

### UX 维度（0 阻断、0 破图、0 console.error）
- **[明显]** 搜索只匹配当前语言（zh 页搜英文 0 结果）；学科列表/首页卡片无完成状态（数据已在 localStorage 只是没渲染）；extras 模块系统性英文泄漏（zh 页 "Veg/Fruit/Protein" 计数、英文大写标题、tooltip）。
- **[细微]** 化学实验 zh 页显示 "Engine descriptions are in Chinese for now."（语义颠倒）；空烧杯有液体填充；电路 SVG 电池标注被裁切 + "conventional current" 未翻译；超长课程页（11k px）无锚点目录；白色沉淀对比度低；计算类真题无自评交互；卡片考纲标签重复；THREE.Clock 弃用警告。

## 二、迭代计划

### 迭代 1：质量债务快速修复（预计 2–3 天）
> 原则：上线前必须堵的口子 + 高性价比 UX 修复，不动结构。

1. **AI 后端滥用防护**（严重）：请求体大小上限、question/history/kpTheory 长度截断、客户端断连 signal 传给上游、文档强调生产必须配 `AI_ALLOWED_ORIGIN`。
2. **README 重写 + 补 AGENTS.md**（严重）：新内容流程（含 `extract:metas`）、完整目录与功能板块、修正"无后端/全原创"表述、Node ≥22.18 与 `.reference/` 获取说明（生成器可复现性）。
3. **extras 英文字符串双语化**（UX 明显，zh 页观感破碎）：lesson-extras 移植层的 UI 文案（计数标签、大写标题、tooltip）。
4. **跨语言搜索**：两种语言的 title/summary/keywords 都纳入匹配。
5. **卡片完成状态角标**：首页/学科页卡片渲染 localStorage 最好成绩。
6. **杂项打包**：chem lab 英文提示只在 en 页显示；空烧杯不渲染液体；电路 SVG 裁切 + "conventional current" i18n；卡片标签去重；THREE.Clock→Timer；`lab/gas.ts` 化学式下标；2 处过期注释；chem-ph-001 probe 描述；3 课小测补足第 3 题；`console.info` 清理 + ESLint（no-console）进 CI；`package.json` engines 字段。
7. **小修**：chunk 加载失败显示"网络错误请重试"而非 404。

### 迭代 2：内容结构统一（预计 1 周）
> 消除双轨体验差异，让每一条学习路径都完整。

1. **转换课 theory 正文回写**：把 narration 的 concept 行转换为 theory 段落（转换器升级 + 重跑），不听讲解的学生也能读到完整教学内容；同时消除 summary 与首段重复。
2. **实验 ↔ 知识点关联机制**：`LabExperiment` 增加 syllabus/related 字段，知识点页加"相关实验"、实验页加"相关知识点"——一次解决"35 个化学课零交互"和"102 实验孤立"两个问题。
3. **手写课结构补齐**（优先 16 课：phy-electric-001/002、phy-force-001~004、chem-stoich-001~004、chem-acidbase-001~004、bio-genetics-001~004）：补学习目标/词汇表；从重叠 IGCSE 课迁移改写真题演练。
4. **同主题双课互链**：重叠课之间加"相关课程"区块。
5. **手写课讲解剧本补齐**：优先 25 个有仿真的课（action 可驱动仿真）。
6. **探针补齐**：45 个无探针手写知识点补 expectedResults（内核现成，工作是算数值）；MCQ 偏少问题（21/412）随内容工作顺带补充。
7. **代码小修**：mmx 双 kernel 调用消除；ParamSpec 类型单源化；server/handler + llm 单测；计算类真题"自评"按钮计入进度。

### 迭代 3：人教版线内容扩充（预计 2 周，走 AI 内容生产管线 + 内核校验 + 人工审校）
> 按中考/高考权重排序，把国内教材线补到与 IGCSE 线对等。

1. **初中物理九年级 6 章**（最优先）：电功率、电与磁、生活用电、能源与可持续发展、信息的传递、内能的利用。
2. **初中生物八年级**：八上全册（动物、细菌真菌病毒、生物多样性）+ 八下"健康地生活"。
3. **初中化学**：溶液单元（溶解度、浓度计算）、走进化学世界、化学与生活。
4. **初中物理八上**：质量与密度、声现象、物态变化。
5. **学段标注精度修正**：bio-eco-002（J/S 曲线）、phy-thermal-002（玻意耳）等映射到正确学段。
6. 高中册深化（物理必修 2/3、化学必修、生物必修/选必）——视前三项完成情况决定是否本期做。

### 迭代 4：AI 与音频落地（预计 1 周，需外部输入）
1. **AI 导师实测调优**（需要你提供 LLM API key）：真实模型问答质量、prompt 调优；后端部署到云函数（先完成迭代 1 的滥用防护）。
2. **TTS 音频批量生成**：按行级剧本跑 edge-tts（83 课 × 行数 × 双语），需能访问 Edge TTS 服务的环境；生成后真机验收音质与音画同步。
3. **Paper 5/6 实验技能模块**（规划级）：IGCSE 实验考试占 20%，两边都未做，差异化空间——本期先做内容规划与 1-2 个试点。

### 迭代 5：上线与深度打磨（按你的节奏）
1. **国内正式上线**：域名 + ICP 备案（建议立即启动，周期 2-4 周）→ 腾讯云 COS + CDN；AI 后端上云函数。
2. **SEO 与无障碍**（你之前明确缓做）：静态预渲染、meta/OG、reduced-motion、键盘导航。
3. **性能二阶**：vendor-katex 懒加载、手写课 Loading 闪烁预取、纯函数测试标注 node 环境提速、生产 Lighthouse 实测。
4. **工程**：测试提速、生成器测试补强、`igcse-statements.ts` 少量 zh 待翻译条目。
